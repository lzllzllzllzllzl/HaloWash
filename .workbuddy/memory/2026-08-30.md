# 2026-08-30

## 修复爆炸/还原幅度 + 模块点击取景

### 根因（重要，易复发）
`src/product/HaloWash.tsx` 存在**双重 Y 偏移**：JSX 外层 `<group position={[0, meta.y, 0]}>` 叠加了
useFrame 里的 `g.position.y = lerp(meta.y, meta.explodedY, e)`，实际世界高度 = `meta.y + lerp(...)`。
结果装配态整摞轮盘悬在球壳上方，根本没收进壳里。
佐证：`FXSystem.tsx` / `particlePool.ts` 用的是正确公式 `m.y + (m.explodedY - m.y) * e`，
特效与轮盘一直是错位的。已移除外层偏移，并把插值收敛为 `moduleYAt()` 单一真源。

### 相机取景（CameraController 全量重写）
三处旧 bug：
1. 用 `meta.y`（装配态）当聚焦目标，但点击会同时把爆炸推到 0.85 → 相机与模块高度完全错位；
2. 距离写死 1.4，比模块直径还小，相机怼进模型；
3. 方位角写死且低位模块会把相机放到地面以下。
新逻辑：每帧按 `explodeCurrent` 实时求模块高度；按 半径+fov+aspect 反解距离（`fitDistance`）；
保留用户当前方位角、俯仰固定 0.2 rad、限制相机 y ≥ 0.75；未选中时按整摞包围盒自适应取景。

### 关键数值约束（改动前先跑 `npm run check:layout`）
- 球壳：centerY 2.55 / r 1.15 / thetaLength 0.75π ⇒ 竖直覆盖 **1.737 ~ 3.700**
- 装配区间 **1.88 ~ 3.07**（间距 0.17，盘厚 0.09，净隙 0.07）；clean(r 0.86) 余量仅 0.043，是最紧的一层
- diagnosis 穹顶顶点 3.665 < 壳顶 3.700 —— 顶部模块再抬高就会穿壳
- 爆炸区间 **0.75 ~ 7.40**（间距 0.95）；底部 0.75 需同时避开底座(0.15)与立臂 |z|
- 半壳分离：dir ±z、dist 3.3，且向**下**沉，避免退出时横在柱体中间

### 自检脚本
`scripts/checkLayout.ts` + `npm run check:layout`（esbuild 转译后 node 运行）。
校验装配包络、爆炸穿模、层间距、各模块取景距离与相机高度。改 partMetadata 后务必跑。
